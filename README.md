# Ruang Tugas

Starter project Next.js dengan tampilan front end statis berbahasa Indonesia. Daftar tugas di halaman utama hanya data contoh; tombol dan filter belum memiliki aksi.

## Menjalankan secara lokal

Gunakan Node.js 20.9 atau lebih baru.

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000). Proyek ini sengaja belum memiliki logika pengelolaan tugas agar bisa dikembangkan sebagai latihan.
